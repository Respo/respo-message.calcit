# Respo Message Calcit 0.13.15 migration

- Fast-forwarded from the latest remote `main` before making changes.
- Upgraded the project and `@calcit/procs` to Calcit 0.13.15.
- Removed the unused, deprecated `lilac` and `memof` dependencies and their
  snapshot module entries; this also removes their transitive `calcit-test`
  dependency.
- Removed the stale `compact.cirru` snapshot, leaving canonical `calcit.cirru`.
- Added unit tests for creating a message and removing one by optional token,
  using the built-in `calcit.test` assertions.
- Added CI scripts and separate compile, unit-test, deprecation, and Vite steps.

Validation: `cr --check-only`, `cr js`, both unit tests, and deprecated API
analysis pass locally. The project retains 21 unresolved Dynamic schema slots
at the public Respo/FFI boundary; this migration does not suppress those
warnings or invent an unsafe Struct contract.
